WHY DESKIT

ちょっとした変換のたびに、迷わない

JSONを整えたい、トークンの中身を見たい、パスワードを1つ作りたい。 そのたびにツールサイトを探していた手間を、アプリひとつにまとめました。

01

Webサイトに貼らなくていい

JWTやアクセストークン、社内のJSONを、検索で見つけたサイトに貼り付けるのは不安なもの。Deskitは変換・整形・生成をすべてアプリの中で行い、入力した内容を外部へ送りません。インターネットにつながっていなくても使えます。

02

探さず、すぐ呼び出せる

⌘K (Windows は Ctrl+K) でツールを検索。日本語名だけでなく、英語名やキーワード (md5・epoch・yml など) でも見つかります。よく使うものはお気に入りに。ほかのツールへ移っても、入力した内容は残ります。

03

日本の開発現場に合わせて

全角・半角やひらがな・カタカナの変換、Shift_JIS のバイト数と原稿用紙の枚数、和暦・年齢・学年の計算まで。画面はすべて日本語です。Git・SSH・AWS のアカウントの切り替えも、ここでまとめて行えます。

WORKFLOW

開いて、貼って、コピーするだけ

設定もアカウント登録もいりません。

STEP 01

ツールを呼び出す

⌘ K を押して、名前やキーワードを数文字。サイドバーのカテゴリやお気に入りからも開けます。

STEP 02

入力する

テキストを貼り付けると、その場で結果が出ます。ハッシュはファイルを選んでも求められます。

STEP 03

コピーして使う

結果の横のボタンでコピー。JSON の書き間違いは、どこが悪いかを行と列で示します。

GIT ACCOUNTS

仕事用と個人用を、取り違えない

「コミットの作者 (名前・メール)」と「接続のしかた (SSH の別名か HTTPS のユーザー名)」を、アカウントとして組で登録。リポジトリを選んで切り替えれば、作者とリモートURLがまとめて設定されます。

  • リポジトリごとに切り替え — 選んだリポジトリの .git/config に作者とリモートURLを書きます。一度設定すれば、切り替え忘れがありません。
  • 食い違いを知らせる — 作者は会社、接続は個人の鍵、のようなずれがあれば表示します。
  • 接続確認 — その別名で、どのユーザーとして認証されるかを確かめられます。
  • ホスト鍵の照合 — 初めて接続するホストは、鍵の指紋を確かめて known_hosts に登録できます (GitHub・GitLab・Bitbucket は公式の指紋と照合)。

SSH HOSTS

~/.ssh/config を、表で直す

接続先 (Host) の別名・ホスト名・ユーザー・ポート・鍵を、一覧から追加・編集・削除できます。GitHub などへの別名も、サーバーへの接続も扱えます。

  • 鍵は選ぶだけ — ~/.ssh にある鍵 (公開鍵と組のもの) から選べます。ほかの場所の鍵は、ファイルを選ぶ画面から指定できます。
  • ほかの行はそのまま — 書き換えるのは選んだ節の決まった行だけ。コメントや Host * の設定は残し、新しい接続先は Host * より前に入れます。
  • 書き換える前にバックアップ — 元のファイルをアプリのデータフォルダに控えます。
  • Gitアカウントとつながる — その別名を使っているアカウントを表示し、消そうとすると知らせます。
AWS PROFILES

どのアカウントに向いているか、ひと目で

AWS CLI のプロファイルを一覧にして、接続確認でアカウントIDやアカウント名、IAMユーザー・ロールを表示します。ターミナルで使うプロファイルも、ここから切り替えられます。

  • 接続確認 — アカウントID・アカウント名・別名・IAMユーザーやロールを表示。名前が読めないときは「権限なし」などの理由も出します。
  • 追加・編集・削除 — ~/.aws/config と ~/.aws/credentials を、画面から直せます。
  • ターミナルの切り替え — 選んだプロファイルを、新しく開いたターミナルの AWS_PROFILE に反映できます (~/.zshrc への連携は任意)。
  • シークレットは出さない — シークレットアクセスキーとセッショントークンは画面に表示しません。

JAPANESE ERA & AGE

和暦も年齢も、入学の年も

生年月日・年・年齢のどれを入れても、和暦・干支・年齢と、小学校から大学までの入学・卒業の年を出します。書類の生年月日の確認や、履歴書の学歴欄を書くときに。

  • いろいろな書き方で入力 — 1990/4/5・平成2年4月5日・H2.4.5・S60・平成二年・36歳 のどれでも読めます。
  • 早生まれも考えて計算 — 1月1日〜4月1日生まれは1年早く入学します。基準日の時点の学年も出します。
  • 元号の切り替わりに注意 — 「平成31年5月1日」のような日付は、令和元年5月1日にあたることを知らせます。
  • 年齢の早見表 — 120年分の西暦・和暦・干支と年齢を一覧にできます。
PASSWORD

サービスの決まりに合わせたパスワードを

「記号はこの8種類だけ」「先頭は英字」のような、サービスごとの決まりに合わせて作れます。条件は次に開いたときも残ります。

  • 使う記号を1つずつ選ぶ — 「よく使われる8種」「26種」「すべて」からまとめて選ぶこともできます。
  • 使う文字は必ず入る — 小文字・大文字・数字・記号のうち、オンにしたものは必ず1文字以上入れます。
  • 読み間違いを防ぐ — 同じ文字を続けない、見間違えやすい英数字 (0 O o 1 l I) を除く、が選べます。
  • 安全な乱数で作る — 暗号に使える乱数 (crypto.getRandomValues) で作り、強さの目安も表示します。

FAQ

よくある質問

無料で使えますか?
無料です。MIT License のオープンソースソフトウェアとして公開しており、商用でもお使いいただけます。
対応OSは?
macOS (Apple Silicon) と Windows に対応しています。Tauri 製のデスクトップアプリなので、ブラウザは必要ありません。
入力した内容が外部に送られることはありますか?
ありません。変換・整形・生成などのツールは、すべてアプリの中で処理します。外部と通信するのは、起動したときに新しいバージョンがあるかを GitHub に確かめるときと、アカウント系のツールで「接続確認」などを行ったときだけです。接続確認は、お使いの git / ssh / aws コマンドが GitHub や AWS などの接続先に直接つなぎます。
設定ファイルを書き換えるのが心配です
ファイルを書き換えるのは、アカウント系の3つのツール (Gitアカウント・SSH接続・AWSプロファイル) で、保存などの操作をしたときだけです。書き換える前に、元のファイルをアプリのデータフォルダの backups/ に控えます (種類ごとに新しい30件)。~/.ssh/config は選んだ節の決まった行だけを書き換え、ほかの行やコメントはそのまま残します。
AWS のシークレットアクセスキーは表示されますか?
表示しません。シークレットアクセスキーとセッショントークンは画面に出さず、アクセスキーIDも一部を伏せて表示します。
git・ssh・aws のコマンドは同梱されていますか?
同梱していません。アカウント系のツールは、お使いのパソコンに入っている git / ssh / aws コマンドを呼び出します。ほかのツールは、何も入れなくても使えます。
新しいバージョンにするには?
新しいバージョンが公開されると、起動したときにアプリの右下に知らせが出ます。「更新して再起動」を押すと、ダウンロードから再起動まで自動で行います。設定 → アップデート の「確かめる」からも確かめられます。更新ファイルには署名が付いていて、アプリが確かめてから入れ替えます。
ダークモードはありますか?
あります。設定 (⌘,) から、ライト・ダーク・システムに合わせる、を選べます。エディタの文字サイズも変えられます。
英語UIはありますか?
Deskit は日本語のアプリで、英語UIは用意していません。ツールの検索は、英語名やキーワード (md5・epoch・yml など) でもできます。
欲しいツールがあります
GitHub の Issues でお知らせください。不具合の報告もこちらへお願いします。
ハッシュは大きなファイルでも求められますか?
求められます。ファイルは少しずつ読みながら計算するので、大きなファイルでもメモリを使いすぎません。MD5・SHA-1・SHA-256・SHA-384・SHA-512 に対応し、期待する値と照合もできます。
